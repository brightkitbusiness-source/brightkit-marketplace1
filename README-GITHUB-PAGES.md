# BrightKit — GitHub Pages package

## Publish the website
1. Create a GitHub repository named `brightkit` (public is simplest for GitHub Pages).
2. Upload the contents of this folder to the repository root (not the parent folder).
3. In GitHub, open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish; the site URL will appear in Settings → Pages.

The site is a responsive static web app and includes a basic installable PWA manifest/service worker. It can be added to a phone home screen from a supported browser. That is not the same as publishing a native app in the Apple App Store or Google Play.

## Current limitations — do not accept payments yet
- Checkout is a demo only; no payment provider or automatic fulfilment is connected.
- Prices are illustrative.
- Privacy, terms, refund and contact pages/business details are not yet configured.
- Product catalogue names, descriptions and the main storefront interface are translated into English, Macedonian, French, German, Russian, Spanish, Spanish (Mexico), Italian and Portuguese. The included downloadable PDF/CSV files are starter editions and are not yet fully translated into all nine languages.
- Review and proofread all translations and product files before commercial sale.

## Mobile app route
The PWA can be installed from the browser. App Store / Google Play publication requires a native app package or approved wrapper, store assets, privacy disclosures, developer accounts, testing and review.
